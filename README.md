# 觀爻 · 六爻排盤原始碼

## 使用方式
解壓縮後，用瀏覽器開啟 index.html 即可使用。所有資源都在同一資料夾，無須安裝套件，也不需要 API 金鑰。

若希望透過本機伺服器開啟，在解壓縮資料夾執行：

    python -m http.server 8000

然後開啟 http://localhost:8000。

## 檔案
- index.html：網頁結構與輸入欄位
- style.css：版面與手機樣式
- app.js：介面互動與排盤結果呈現
- engine.js：八宮、納甲、六親六獸、世應、飛伏神與十二長生計算
- lunar.js：第三方曆法函式庫 lunar-javascript
- favicon.svg：網站圖示

## 規則
- 台灣標準時間 UTC+8；不校正真太陽時。
- 立春換年、十二節交接換月。
- 可選午夜 00:00 或子初 23:00 換日。
- 日期輸入範圍 1900–2100。
- 六爻由初爻往上輸入；6 老陰、7 少陽、8 少陰、9 老陽。
- 十二長生採土寄水宮，分別列出月建與日辰狀態。
- 變爻六親依本卦宮五行。
- 日沖只標示日沖，不推定暗動或日破。
- 僅排盤與關係標注，不作吉凶、健康或應期判斷。

## 第三方曆法
lunar-javascript：https://github.com/6tail/lunar-javascript
原始檔案保留其既有註解與授權標示。

## 換日顯示修正
農曆曆日固定午夜換日；子初換日時另列排盤採用日，避免把兩種日期混在一起。日柱、時干、旬空與六獸依所選規則同步。

測試：node tests/calendar.cjs（需 Node.js）。

## 一鍵起卦
使用瀏覽器 crypto.getRandomValues，六爻各自獨立。每爻老陰、老陽各 2/16，少陰、少陽各 6/16，因此動爻機率為 2/8，陰陽各半。保留已選占卦時間，直接填入六爻並更新盤面。動爻數量不固定。
測試：node tests/random.cjs。

## 響應式版面
電腦與手機均保留相同六欄橫式排盤、欄名及上爻至初爻的順序，不轉成卡片。空間不足時，整張表格依可用寬度等比例縮放，完整顯示右側變卦與動變標注，不需左右捲動。字體與爻線會隨表格縮小；瀏覽器仍可手動放大。縮放同時調整表格占用高度；起卦、旋轉螢幕與開啟十二長生參照表時重新計算。小於 400px 的四柱區仍採兩欄；手機輸入字體為 16px。

## 動爻符號
老陰、老陽選項與盤面不再顯示 O／X（○／×）。仍保留動爻顏色、狀態與變卦計算。

最新橫向捲動相容修正只需替換 app.js。縮放程式會同步固定容器裁切、左上角縮放原點與表格定位，避免舊版 style.css 的 overflow-x:auto 及未縮放的原始寬度留下捲動條；並重設舊的捲動位置。完整版仍附更新過的 style.css，可一併替換。其餘檔案不變。
